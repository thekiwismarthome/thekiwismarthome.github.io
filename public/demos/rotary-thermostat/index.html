    Things to try

    • Turn the dial on the main screen to change the target. Notice it moves by 0.5 degrees a click.
    • Press to open the ring menu. Turn to pick an icon, press to choose it. The label in the middle names the one you are on.
    • Set the mode to Off, then turn the dial. It switches the system on first, as the real one does.
    • Choose Fan only. The temperature scale disappears and a big fan icon shows.
    • Turn the network delay up and spin the dial quickly. Each click sends the last confirmed target plus 0.5, so fast turns can lose steps. That is how the config works today.
